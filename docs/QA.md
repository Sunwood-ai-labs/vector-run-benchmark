## 自動テスト

```sh
npm test
npm run test:http
```

対象は Seed の決定性、難易度の上限、衝突判定、入力の押し/離し、2段目の上限・着地リセット、旧1段エンジンとの互換性、入力ログの再生、ジャンプ規則と操作方法ごとの別集計、時計中断の無効化、ローカル HTTP 配信です。

テストはローカルで完結し、ゲーム記録を外部サービスへ送信しません。オフラインのコース実行テストは実時間のモデル評価スコアではありません。

## ブラウザ操作チェックリスト

`npm run serve` で起動し、同じコンピューターのブラウザで http://127.0.0.1:4173 を開きます。DevTools での強制停止や時間操作は使わず、通常の操作を確認します。

1. 初期表示: 2段ジャンプ / Seed 101 が選択され、距離0・READYが見える
2. 開始: 「ランを開始」で走行が始まり、距離と生存時間が増える
3. 2段ジャンプ: Spaceを短く押して離し、空中で再度押す。3回目は無視され、着地後に回数が戻る
4. 長押し: 押したまま着地しても自動で再ジャンプしない
5. 1段ジャンプ: 停止後に1段を選択すると、空中の再入力は無視される
6. 終了と再開: 接触で結果と履歴が出る。「もう一度走る」で距離と時間が0から再開する
7. 中止: 中止は無効として残り、平均に含まれない
8. 中断: 別タブへ切り替えると無効となる。戻っても走行を再開しない
9. 保存: JSON/CSVを保存し、Seed・版・規則・スコア・終了理由を確認する
10. 再生: 履歴の「再生」と保存JSONの読み込みで再現し、履歴数・平均に新しい成績を追加しない
11. 集計: 1段/2段、手動/Agent/未操作を切り替え、記録が混ざらない
12. 練習: 練習の記録をベンチマークの平均に含めない

## 画面とアクセシビリティ

次の条件で、初期表示・走行中・結果・再生の実スクリーンショットを確認します。画像がまだない段階では README にダミー画像を掲載しません。

- デスクトップ: 1280 × 800 と 1440 × 900
- モバイル: 390 × 844 と 360 × 800
- 狭い画面でも文字やスコアが重ならず、横スクロールが発生しない
- スタートとジャンプが最初の画面から操作できる
- キーボードのフォーカスが見え、Space/↑/W が意図した動作をする
- タッチで押し/離しが成立し、ジャンプ中にページが意図せずスクロールしない
- 結果、集計対象外の理由、再生中の表示が読み取れる

モバイルの幅を再現したデスクトップ画面と、実際のタッチ端末での試験は区別して記録します。

## スコアの取り扱い

実時間ランでは100 ms超のフレーム中断、非表示、フォーカス喪失を無効にします。UIテストの成績はモデルランキングに使いません。比較には同じエンジン版・設定ハッシュ・ジャンプ規則・操作方法・Seed集合を使います。
